## En qué estoy trabajando

Mi foco actual es **AXX**, un asistente para Windows con una presencia 3D en el escritorio. Combina conversación, opciones de voz local y herramientas de automatización con proveedores de IA configurables.

También desarrollo proyectos de captura y reconstrucción voxel, aplicaciones web y producción audiovisual con código.

## Proyecto principal · AXX

[![Interfaz de AXX: personaje 3D y menú circular de herramientas](https://raw.githubusercontent.com/luigilaxmaster-coder/AXX/main/docs/images/showcase/desktop-orbit.png)](https://github.com/luigilaxmaster-coder/AXX)

- **Escritorio:** aplicación residente para Windows con interfaz 3D y accesos circulares.
- **IA y voz:** selección de proveedores, modelos locales y herramientas de voz.
- **Herramientas:** memoria persistente, integración MCP y acciones de escritorio con permisos.
- **Conexión móvil:** aplicación complementaria Android para comunicarse con el PC.

**Python · Rust · Tauri · JavaScript · WebGL · SQLite**

[Explorar el proyecto](https://github.com/luigilaxmaster-coder/AXX) · [Descargas y versiones](https://github.com/luigilaxmaster-coder/AXX/releases) · [Documentación](https://github.com/luigilaxmaster-coder/AXX/tree/main/docs)
